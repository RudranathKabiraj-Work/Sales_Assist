# Taste

## Design & styling
- Prefers landing page sections to be visually separated from one another using distinct/alternating background colors so each block reads as its own area. Confidence: 0.7
- Dislikes hover effects that shift or visually zoom the page/sections (e.g., scale transforms on buttons); prefers subtle hovers like a light lift + shadow that leave the layout still. Confidence: 0.5
- Likes expressive, animated hover micro-interactions on CTAs (e.g., a "rolling hills" effect where layered shapes rise and drift) — wants hovers to feel "damn beautiful" and premium, not just a color/background swap. Confidence: 0.6
